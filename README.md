# Enterprise Ecommerce Blueprint

Next.js 14, TypeScript, TailwindCSS, Prisma ve çok modüllü admin panel ile KleiderMafia + TechUI esintili e-ticaret altyapısı için başlangıç şablonu.

Kurulum komutları:
1. `npm install`
2. `.env` dosyasında `DATABASE_URL` vb. ortam değişkenlerini tanımla
3. `npx prisma migrate dev`
4. `npm run dev`
